年代や月収によって普段の食事に支払う金額は変わるのか？朝食・昼食・おやつ・夕食それぞれで分析した結果

GIGAZINEが実施したアンケート調査により、年代や月収によって食費の配分が異なることが明らかになりました。回答者は、朝食やおやつは手頃な価格に抑え、夕食に費用をかける傾向が見られました。
