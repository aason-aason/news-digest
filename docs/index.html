フランスのスーパー数百店舗で冷蔵設備にサイバー攻撃、食品大量廃棄と火災発生

フランスのスーパーマーケット数百店舗で、冷蔵・冷凍設備の霜取り機能に対するサイバー攻撃が発生し、庫内温度が最高50度まで上昇して食品が大量廃棄され、火災も発生しました。これは、IoT機器へのサイバー攻撃が実社会に深刻な影響を与える事例として注目されます。

Microsoft、第3世代AIチップ「Maia 300」を2027年に投入、GPU比で電力効率4割向上

Microsoftは、自社設計の第3世代AIアクセラレータ「Maia 300」を2027年に投入すると発表しました。TSMCの2nmプロセスを採用し、GPUと比較して電力効率が4割向上し、処理能力も最大7倍になるとのことです。これは、AIインフラストラクチャにおけるMicrosoftの競争力強化を示す重要な動きです。

Maia 300はTSMCの2nmプロセスで製造され、288GBのHBM4を搭載します。推論処理に特化しており、GPU基盤と比較して電力効率が大幅に向上します。Microsoftはこのチップを数ギガワット規模で展開し、自社サービスの主力推論基盤として活用する予定です。
