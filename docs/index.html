X、「クリエイター収益分配プログラム」終了へ──「オリジナル投稿」に絞った新報酬制度に移行

X（旧Twitter）は、クリエイター収益分配プログラムを終了し、新しい報酬制度「Original Content Rewards Program」に移行することを発表しました。この変更は、無断転載やインプレゾンビ対策として、自作コンテンツの重要性を高めるものです。

新制度では、有料会員の有効インプレッションに応じて報酬が支払われます。これにより、質の高いオリジナルコンテンツを投稿するクリエイターへのインセンティブが強化される一方、コンテンツの質が低い場合や無断転載の場合は収益が得られにくくなる可能性があります。既存制度からの申請は9月から開始されます。

Native InstrumentのSuperStarSawレビュー

Native InstrumentのSuperStarSawは、その名の通り「スーパーソー」サウンドに特化したシンセサイザーですが、それ以上の多様なサウンドメイクが可能です。90年代のトランスミュージックを定義したサウンドを再現しつつ、現代的なエレクトロニックミュージックのニーズにも応えられるポテンシャルを秘めています。
