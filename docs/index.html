J:COMネット障害、原因は「外部からの大量アクセス」　DNSサーバに高負荷　最大約408万件に影響

J:COMのインターネットサービスで大規模な障害が発生し、最大約408万件の契約者に影響が出ました。原因は外部からの大量アクセスによるDNSサーバーへの高負荷とのことです。障害情報の公開に時間がかかったことも謝罪されており、インフラ障害対応の迅速化が課題となります。

J:COMのインターネットサービスにおいて、外部からのDDoS攻撃とみられる大量アクセスによりDNSサーバーに高負荷がかかり、大規模な通信障害が発生しました。この障害により、最大約408万件の契約者（約408万回線）がインターネットに接続できなくなりました。復旧には時間を要し、障害情報の公開が遅れたことについても謝罪がありました。このようなインフラ障害は、広範囲に影響を及ぼすため、迅速な原因究明と復旧、そして透明性のある情報提供が不可欠です。

ハルシネーション排除、最大200倍高速――元OpenAI研究者の新AI「Jev」は何が違うのか

元OpenAIの研究者が開発したTypeSafe AIの新しいAIモデル「Jev」が、文字列生成を廃止し、従来のLLMと比較して最大200倍の高速化とハルシネーション（幻覚）の排除を実現したと発表しました。このAIは自動化に特化しており、精度と効率を重視する用途での活用が期待されます。
