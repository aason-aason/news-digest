この記事では、シンセサイザープラグイン「Diva」を使用して、オリジナルのキックドラムサウンドを作成するステップバイステップガイドを提供しています。豊富なキックドラムサンプルが存在する中で、独自サウンドを作成するメリットとして、トラックに合わせた調整、オリジナリティの付与、そしてサウンドメイキングの楽しみが挙げられています。808や909スタイルのキックサウンドを基本に、様々な音作りが可能であることを解説しています。

チュートリアルは7つのステップで構成されており、オシレーターの設定からエンベロープ、フィルターの調整まで、キックドラムのサウンドデザインに必要な要素を網羅しています。特に、ピッチエンベロープの応用や、アンプエンベロープ、フィルターセクションの活用方法が詳しく説明されています。さらに、ベースラインツールとしての活用法や、アナログモデリング特有のバリエーションへの対処法といったボーナスのヒントも提供されており、実践的な内容となっています。

ソフトウェアおよびハードウェアトラッカーのベスト5

この記事は、音楽制作における「トラッカー」と呼ばれるシーケンサーソフトウェア・ハードウェアのベスト5を紹介しています。トラッカーは、従来のDAWとは異なる縦方向のインターフェースを持ち、特にJungle、IDM、Breakcoreなどのジャンルで有効です。SunVox、TRX-12、Renoise、Dirtywave M8、Polyend Tracker+が紹介されており、それぞれの特徴や価格帯についても解説されています。

トラッカーは、1987年にCommodore Amiga用に登場したUltimate Soundtrackerに起源を持ち、数字でノートやパラメータ情報を表現する独特のワークフローを持っています。この記事では、無料のSunVoxから、Mac/PC用のTRX-12、高機能なRenoise、ポータブルなハードウェアのDirtywave M8、そして最新のPolyend Tracker+まで、幅広い選択肢が提示されています。それぞれのデバイスやソフトウェアが、どのような音楽制作スタイルに適しているか、またその価格についても触れられています。

BMW新型SUV「iX3」ついに日本上陸！「"駆けぬける歓び"」だけではない新世代BMWの核心は何か？

BMWの新型SUV「iX3」が日本に上陸しました。従来の「駆けぬける歓び」というブランドイメージに加え、新世代BMWの核心となる要素が何であるかが問われています。電気自動車（EV）としての性能や、BMWブランドの将来像に焦点が当てられた記事です。

BMW iX3は、BMW初の完全EV SUVとして注目されています。この記事では、iX3が単なる電動化されたモデルではなく、BMWのブランド哲学や技術革新がどのように反映されているかを分析しています。単なる走行性能だけでなく、デザイン、インフォテインメントシステム、そして持続可能性といった側面から、新世代BMWの目指す方向性が探られています。サッカー選手の中村敬斗氏が発表会に登場したことも話題となりました。
