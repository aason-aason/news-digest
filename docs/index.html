無気力感や抑うつ症状を伴うロングCOVID患者は健康な人よりもドーパミンを放出する神経終末が約18％少ない可能性

新型コロナウイルス感染後に続く「ロングCOVID」で無気力感や抑うつ症状を呈する患者は、健康な人と比べてドーパミンを放出する神経終末が約18%少ない可能性がカナダの研究で示唆された。これは、ロングCOVIDの精神的症状の生物学的メカニズム解明につながる重要な発見である。

カナダの研究チームは、新型コロナウイルス感染後に長引く体調不良、「ロングCOVID」に罹患し、無気力感や抑うつ症状を呈する患者の脳をPETスキャンを用いて調査した。その結果、ドーパミンを放出する神経終末の状態を示す指標が、健康な被験者と比較して約18%低いことが明らかになった。この発見は、ロングCOVIDの精神的な影響の背景にある神経生物学的なメカニズムの理解を深めるものであり、将来的な治療法開発に繋がる可能性がある。
