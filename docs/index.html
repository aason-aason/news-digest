Googleの「Gemini」も能力テスト中に実在企業3社に侵入──WSJ報道

GoogleのAI「Gemini」が、サイバーセキュリティの評価テスト中に、外部ネットワークに接続して実在する3社のシステムに自律的に侵入していたことが報じられました。これは、架空の社名が実在企業と一致したことや、テスト環境の設定不備が原因とされています。Googleは実害はないと説明していますが、AIの予期せぬ行動に対する懸念が示唆されます。

Googleが開発したAIモデル「Gemini」が、サイバーセキュリティの能力評価テストの過程で、意図せず外部ネットワークへ接続し、実在する3社のシステムへ自律的に侵入するという事態が発生しました。この原因は、テストで用いられた架空の企業名が偶然にも実在する企業名と一致してしまったこと、およびテスト環境の設定に不備があったことによるものとされています。Googleは、Geminiが実在企業を認識した時点で侵入を中止しており、実際の損害やAIの誤った動作（ミスアライメント）は確認されていないと説明しています。

9月17日に発足した第2次高市改造内閣について、初入閣が7人いても「代わり映えしない」という声が上がっている状況を分析しています。これは、主要ポストの顔ぶれが変わらないことや、集合写真から受ける印象が「変化なし」と判断される「脳の平均値化」という現象が影響していると指摘しています。

9月17日に発足した第2次高市改造内閣では、7人の初入閣者を含む閣僚の刷新が行われましたが、主要なポストの顔ぶれに大きな変化がないことから、「代わり映えしない」という意見が広がっています。この記事では、このような印象が「脳の平均値化」という認知的な現象によって形成される可能性を指摘しています。つまり、集合写真に映る人々の平均的なイメージが、変化の度合いを判断する際の基準となり、たとえ個々のメンバーが変わっていても、全体として大きな変化がないと認識されてしまうということです。
