自閉症の人には「他の自閉症の人の気持ちが分かる」という強みがあるかもしれない

イスラエルのヘブライ大学やイギリスのケンブリッジ大学などの研究チームは、自閉症の人が他の自閉症の人の気持ちを理解する能力において、自閉症ではない人よりも優れている可能性があるという研究結果を発表しました。従来の研究が自閉症ではない人の感情理解に焦点を当てていたのに対し、この研究は自閉症の人同士の相互理解という新たな視点を提供しています。
