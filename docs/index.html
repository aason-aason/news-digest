X、プライバシー重視のフロントエンド「Nitter」にスクレイピング疑惑で文書送付

Xは、プライバシー重視のXフロントエンドを提供するオープンソースプロジェクト「Nitter」に対し、スクレイピング疑惑を理由にインスタンスとコードリポジトリの削除を求める文書を送付しました。これにより、Nitterの利用や開発に影響が出る可能性があります。

X（旧Twitter）は、ユーザーがXのプラットフォームに直接アクセスすることなく、よりプライベートな方法でツイートを閲覧できるオープンソースフロントエンド「Nitter」に対して、文書送付（cease-and-desist letter）を行いました。XはNitterがXのデータを不正に収集（スクレイピング）していると主張しており、インスタンスの停止とコードリポジトリの削除を要求しています。この動きは、Xのプラットフォームへのアクセス方法や、オープンソースプロジェクトと大手プラットフォームの関係に影響を与える可能性があります。
