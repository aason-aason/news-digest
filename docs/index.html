自分の家の中でも迷子になってしまう「発達性地誌的見当識障害」とは？

一部の人は、自宅のような慣れた場所でも方向感覚を失う「発達性地誌的見当識障害（DTD）」を抱えています。ライデン大学の研究によると、これは頭の中に場所のつながりを示す地図を作成できない状態と関連しています。

発達性地誌的見当識障害（DTD）は、空間ナビゲーションの困難さとして現れ、日常生活に影響を与える可能性があります。この障害は、脳の空間認識や記憶に関連する機能の個人差に起因すると考えられています。研究は、この障害のメカニズムを解明し、支援策の開発に繋げることを目指しています。
