OpenAIがプロンプトインジェクション攻撃から機密データを保護する「ロックダウンモード」を発表

OpenAIは、ChatGPTに新しいセキュリティ機能「ロックダウンモード」を導入しました。この機能は、プロンプトインジェクション攻撃による機密データの漏洩リスクを低減することを目的としています。モードを有効にすると、Webブラウジングや外部サービスへの接続が制限されるため、機密情報を扱うユーザーや組織にとって重要な保護策となります。

ChatGPTの「ロックダウンモード」は、悪意のあるプロンプトによって、モデルが意図せず機密情報を提供したり、外部サービスと危険なやり取りをしたりするのを防ぐために設計されています。このモードを有効にすると、ChatGPTはWebブラウジング機能やプラグイン、コードインタプリタなどの外部ツールへのアクセスを制限します。これにより、ユーザーの入力情報が外部に漏洩するリスクを最小限に抑えることを目指しています。OpenAIは、この機能によってChatGPTの安全性が向上し、より安心して利用できるようになると説明しています。

moomoo証券、監視委が処分勧告　NISA対象外を「対象」と虚偽説明　顧客対応も「著しく杜撰」

証券取引等監視委員会は、moomoo証券に対して行政処分を金融庁に勧告しました。勧告の理由として、NISA口座の対象外である米国ETF・ETNを「対象商品」と偽って販売したことや、顧客対応における著しく杜撰な実態が挙げられています。これは投資家保護の観点から重大な問題と判断されています。

moomoo証券は、NISA制度の対象とならない金融商品をあたかも対象となるかのように説明し、販売していました。これにより、一部の投資家は意図せずNISA枠を消費したり、税制上の優遇措置を受けられなかったりする可能性が生じました。さらに、株式の出庫申請を一方的に拒否するなど、顧客の権利を侵害するような対応も問題視されています。監視委員会は、これらの行為が金融商品取引法に違反し、投資家保護の観点から看過できないとして、厳格な処分を求めています。

規則正しい生活リズムで暮らすことが生物学的老化を遅らせる鍵かもしれない
