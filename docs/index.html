UVI Rumbleレビュー：ベースシンセシスへの新アプローチ

Buchert Audio、macOS用無料ステレオ幅プラグイン「The Double Wide」をリリース

Buchert Audioは、macOS用の無料ステレオ幅プラグイン「The Double Wide」をリリースした。このプラグインは、シンプルなワンノブ操作でステレオ信号の幅を狭めたり広げたりできる。音源のステレオ感を調整したい場合に役立つ。

「The Double Wide」は、その名の通り、ステレオ信号の「幅」を直感的に調整できるツールである。ノブを左に回すとモノラルに近づき、右に回すとステレオ感が広がる。複雑な設定はなく、手軽にステレオイメージを操作できるため、ミックスの初期段階や、特定のトラックのステレオ感を微調整したい場合に便利である。
