熊本地震による通信障害、携帯4社全てで復旧

NTTドコモ、KDDI、ソフトバンク、楽天モバイルの携帯4社は7月30日、令和8年熊本地震で熊本県内に出ていた通信障害が全て復旧したと発表した。ただし被災地では応急復旧が続き、通信速度が遅くなる場合があるとしている。

脳は「真のマルチタスク」を実現するために再配線できるとの研究結果
