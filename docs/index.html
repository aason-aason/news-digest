トランプ米大統領の娘婿ジャレッド・クシュナー氏が出資するアルバニアの大型リゾート計画が、土地権利証書の偽造疑惑で批判を受けています。この計画はアルバニア国民から猛反発を受けており、開発用地の権利を巡る不正の可能性が指摘されています。

このリゾート計画は、数十億ドル規模の大型プロジェクトであり、観光開発による経済効果が期待される一方で、土地の権利関係に問題があるとの疑惑が浮上しています。マイアミ在住の実業家が開発用地の土地権利証書を偽造した疑いが報じられており、これが計画の透明性や正当性に疑問を投げかけています。クシュナー氏のような著名な人物が関与していることから、この問題は国際的にも注目されています。開発の進め方や法的問題について、さらなる調査が求められています。
