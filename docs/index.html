OpenAI、SpaceXによる買収を理由にCursorへのモデル提供を11月12日に終了

OpenAIは、AIコードエディタ「Cursor」へのモデル提供を11月12日に終了すると発表しました。SpaceXによるCursorの買収が理由であり、OpenAIはイーロン・マスク氏の過去の契約違反実績から、規約遵守を確信できないとしています。Cursor側は影響は限定的とし、協議継続を表明、Anthropicは支援継続を示しました。

この決定は、AI開発コミュニティにおいて波紋を広げています。Cursorは、OpenAIのモデルを活用して開発されており、今回の提供終了はCursorの機能に影響を与える可能性があります。OpenAIの姿勢は、AI開発におけるパートナーシップの難しさや、企業間の信頼関係の重要性を示唆しています。一方、AnthropicがCursorへの支援を継続する意向を示したことは、AIエコシステムにおける協力関係の可能性を示唆しています。
