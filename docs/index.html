Geminiがスマホを“自動操縦”　Google、Android向けAIエージェント「Gemini Intelligence」発表

GoogleはAndroid向けAIエージェント「Gemini Intelligence」を発表しました。これは、複数のスマートフォンアプリを横断してタスクを処理し、ユーザーの代わりにスマホを操作する機能を持っています。
