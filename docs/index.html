「うるう秒」は2026年12月末も挿入されず、最後の「うるう秒」から10年

国際地球回転・基準系事業(IERS)は、2026年12月末もうるう秒を挿入しないことを決定しました。これにより、最後のうるう秒挿入から10年間、うるう秒は挿入されないことになります。これは、計時システムにおける標準化の動きを示唆しています。

うるう秒は、天文時間と原子時間のずれを調整するために挿入されますが、近年その必要性や挿入方法について国際的な議論が進んでいました。IERSの決定は、将来的なうるう秒廃止に向けた一歩となる可能性があります。これにより、GPSなどのシステムにおける計時精度への影響が注目されています。
