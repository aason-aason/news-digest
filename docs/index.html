Anthropic、AIで物理機器を制御する共通規格「MHS」発表　将来オープンソース化へ

Anthropicは、AIエージェントが物理機器を安全に操作するための共通仕様「Model Hardware Standard」（MHS）を発表しました。これにより、機器の統合作業が大幅に短縮され、基本命令や安全制限の標準化による自律制御が可能になります。将来的にはオープンソース化される予定です。

MHSは、AIが実験・製造機器などを安全かつ効率的に操作できるように設計された標準仕様です。これにより、異なるメーカーの機器間での連携が容易になり、AIによる自律的なオペレーションが推進されます。Anthropicは、先行導入事例を公開し、安全性評価を進めた上で、この仕様をオープンソースとして公開する方針です。
