好きなことを仕事にするとなぜ苦しくなるのか？ 報酬を与えられたためにやる気がなくなる不思議な心理学効果

この記事は、文学紹介者・頭木弘樹氏による連載「ビジネスと人生は絶望に満ちている」の一部です。「好きなことを仕事にする」という考え方に対して、報酬が与えられることでかえってやる気が低下するという心理学効果（アンダーマイニング効果）に言及し、それがなぜ起こるのかを考察しています。

「好きなことを仕事にする」という現代社会でよく語られるスローガンに対し、一石を投じる記事です。心理学における「アンダーマイニング効果」を引用し、本来内発的な動機（好きという気持ち）で取り組んでいた活動に、外的な報酬（お金）が与えられることで、かえってその活動への意欲が低下してしまう現象を解説しています。著者は、この効果が「好きなことを仕事にする」という考え方の落とし穴となり得ることを示唆し、ビジネスや人生における報酬とモチベーションの関係性について深く考察しています。

🟡 重要 東洋経済オンライン

外資ファンドが｢安い日本｣をビジネスに利用し始めた――中国で日本産のリンゴが1個800円弱で売られている

日本円安を背景に、海外資本が日本市場の「安さ」を利用したビジネス展開を始めています。中国では日本産リンゴが1個約800円で販売されるなど、農産物価格の異常な高騰にも触れ、長年の政策による歪みが指摘されています。

この記事は、円安によって日本の資産や商品が海外から割安に見える状況を利用した、外資ファンドによるビジネス展開に焦点を当てています。特に、中国市場における日本産リンゴの異常な高価格設定は、日本国内の生産者や消費者への影響、そして国内政策の歪みが指摘されています。高市政権の政策が外資に有利な状況を生み出している可能性にも言及しており、日本経済の現状と今後の展望について警鐘を鳴らしています。
